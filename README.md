Welcome reader! This is the first Caramelofy project and experiment for the game Dreamed Hides. 🚀



\### Purpose

To experiment with setting up the whole process for the game "Dreamed Hides" in a console version, in its most simple form (hardcoded and single-file approach), to learn more about the whole process and gain insights from a simpler holistic perspective. Consisting of three parts: Fox.Sender project, Fox.Receiver project and Fox.GameServer project.
